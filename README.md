# はむあつめ 🐹

ブラウザで遊べる、ハムスターを集める放置ゲームです。
おへやにえさとグッズを置いておくと、時間の経過とともにハムスターが遊びに来ます。
遊びに来たハムスターは「はむ図鑑」に登録され、帰るときに「おみやげ（ひまわりの種）」を残していきます。

## 遊び方

1. **えさ** タブでえさを選んで、えさ皿（2 か所）に入れる
2. **ショップ** タブでグッズを買い、**おへや** の空きスロットに置く
3. しばらく待つ（ブラウザを閉じていても時間は進みます）
4. 遊びに来たハムスターをタップして詳細を見る／**はむ図鑑** を埋めていく

## 動かし方

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動きます。
GitHub Pages で公開する場合は、Settings → Pages → Branch を `main` / `(root)` にしてください。

## 構成

```
index.html      エントリ
css/style.css   スタイル
js/data.js      ハムスター・グッズ・えさの定義
js/art.js       ドット絵描画（ハムスター ポーズ×カラー、グッズ、背景）
js/game.js      ゲーム状態・来訪シミュレーション・セーブ
js/ui.js        画面描画
js/main.js      起動
design/         画面モックアップ（Claude Design 形式）、sprites.html（ドット絵一覧）
```

セーブデータはブラウザの localStorage に保存されます。
